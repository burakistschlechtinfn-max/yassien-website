1. Ableitungsregeln

f(x) = xⁿ ⇒ f'(x) = n · xⁿ⁻¹

f(x) = eˣ ⇒ f'(x) = eˣ

f(x) = ln(x) ⇒ f'(x) = 1/x

Grundlage zur Bestimmung der Steigung in Kurvenpunkten.

2. Extremwertbestimmung

  • Notwendige Bedingung: f'(x₀) = 0
  • Hinreichende Bedingung: f''(x₀) ≠ 0
  • f''(x₀) < 0 ⇒ Hochpunkt (Lokales Maximum)
  • f''(x₀) > 0 ⇒ Tiefpunkt (Lokales Minimum)

3. Wendepunkte

Ein Wendepunkt beschreibt die Änderung des Krümmungsverhaltens des Funktionsgraphen.

f''(x_w) = 0 & f'''(x_w) ≠ 0
